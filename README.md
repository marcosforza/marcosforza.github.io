## About the Template

This site is powered by the [Academic Pages template](https://github.com/academicpages/academicpages.github.io). If you wish to build your own site using this structure:
- Check the [Academic Pages Guide](https://academicpages.github.io/) for documentation and setup instructions.
- Refer to this [step-by-step tutorial](https://jayrobwilliams.com/posts/2020/06/academic-website/) by Jay Rob Williams.
- Template bug reports and feature requests should be submitted directly to the [upstream repository](https://github.com/academicpages/academicpages.github.io/issues).
